# Erikka Miles — Artist Portfolio

Portfolio site for Erikka Miles, artist and LAUSD art educator based in Los Angeles.

Single-page site (`index.html`) with tabbed navigation:

- **Home** — hero placeholder for a feature piece
- **Work** — 20 reserved slots for the pieces in progress
- **Exhibition** — 5 slots, one per show, for the 5×/year commitment
- **Shop** — 20 listing slots (Stripe checkout to be wired up later)
- **About** — Erikka's story
- **Contact** — email and social links

No build step. Open `index.html` in a browser.
